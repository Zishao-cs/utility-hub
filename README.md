# Zishao's Integrated Utility Hub

A comprehensive digital portfolio featuring four self-developed web applications. This project demonstrates my proficiency in front-end development, logic implementation, and clean code architecture.

## 🚀 Featured Applications

1.  **Task Manager (Productivity)**: A CRUD-based Todo list utilizing DOM manipulation for dynamic task updates.
2.  **Snake Challenge (Entertainment)**: A retro arcade game built with HTML5 Canvas API and JavaScript game loop logic.
3.  **Focus Timer (Academic)**: A Pomodoro-style study tool using high-precision timing functions.
4.  **Flashcard Pro (Study)**: An interactive learning tool featuring CSS 3D transforms and data-driven content management.

## 🛠 Technical Stack
- **HTML5**: Semantic structuring for accessibility and SEO.
- **CSS3**: Modern layouts using Flexbox/Grid and 3D animations.
- **JavaScript (ES6+)**: Logic implementation and user interaction handling.
- **Project Structure**: Modular folder hierarchy for professional scalability.

## 🎓 Academic Reflection
Through this project, I explored the intersection of UI/UX design and functional programming. Managing multiple sub-projects taught me the importance of file organization and relative path management—key skills for any modern developer.
